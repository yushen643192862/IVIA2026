# 双 Basler 相机拍摄

连接及 BGR 转换参考 `lab1/Lab1_Group4/Code/grab_basler1.1.py`，扩展为两台独立相机和两个抓帧线程。

```powershell
python lab5/capture_stereo.py
```

左右画面在一个窗口实时显示，窗口默认位于桌面原点附近，便于把屏幕 2 留给投影仪。点击预览窗口让它获得键盘焦点：

- **S 或 P**：保存当前显示的一对完整分辨率 BMP，依次为 l1.bmp/r1.bmp、l2.bmp/r2.bmp，不含预览文字与框。
- **W**：让同一张无反光白纸占满两路画面的中央黄色框，在全白投影/实际拍摄照明下校准白平衡。按键直接在获得焦点的预览窗口中使用，不在终端输入，也不用回车。
- **Q / Esc** 或关闭窗口：停止采集并释放两台相机。

首次默认按序列号排序选择两台相机，请看窗口标题中的 LEFT/RIGHT 和序列号确认物理左右。顺序反了可退出后用 `--swap`；推荐用序列号固定角色：

```powershell
python lab5/capture_stereo.py --list
python lab5/capture_stereo.py --left-serial 左相机序列号 --right-serial 右相机序列号
python lab5/capture_stereo.py --check
```

可选 `--exposure-us 10000 --gain 0`；未指定时以左相机当前值为准。程序关闭可用的自动曝光、自动增益和自动白平衡，在采集前将右相机的成像设置同步为左相机的值：像素格式、分辨率/ROI、采样模式、曝光、增益、RGB 白平衡比例、黑电平、Gamma，以及可用的帧率和颜色变换设置。RGB 等依赖 selector 的参数逐项复制。每项均读回校验，不兼容或复制失败时停止采集，控制台显示具体项目。

左相机的参数是同步基准；不加载默认用户配置。同步右相机的 ROI、像素反转或采样模式可能影响此前右相机标定，应保证后续标定和场景拍摄使用同一组设置。设备序列号、网络/USB 传输参数等不属于成像参数，不复制；启用自定义 LUT 时程序会报错，避免只复制开关而遗漏表数据。同步记录保存到 session.json，每对照片的元数据也包含实际匹配的成像参数。

两机参数相同不保证颜色完全一致。W 使用两路中央白纸区域分别计算固定的软件 BGR 增益，使白纸接近中性并匹配亮度；应用于完整分辨率图像、预览和保存照片。不会持续自动调整或更改硬件白平衡，参数记录在 white_balance.json 和每对元数据中。截图本身不用于估算参数。校准后移开白纸，再拍摄条纹；第一次保存后 W 锁定，要重新校准须重启新会话。每次新会话需重新 W 校准，不自动复用上次照明条件下的参数。需先退出旧版窗口以释放设备。

每次启动建立新 session，S/P 连续编号保存一对：

```text
lab5/captures/session_日期时间/
  session.json
  white_balance.json
  l1.bmp
  r1.bmp
  pair_1.json
  l2.bmp
  r2.bmp
  pair_2.json
```

pair_N.json 记录相机角色、设置、帧编号、设备时间戳、主机接收时间及软件白平衡增益。先暂存两图及元数据，再移入会话目录；写入异常会清理本次不完整文件，不覆盖已有照片。预览分辨率由 `--panel-width 640` 控制，保存尺寸不受影响。应用白平衡后可能发生少量高亮裁切，应避免白纸过曝。

使用静止场景，投影图案稳定后再按 P。两相机连续独立曝光，按 P 保存两路最新显示帧，**不是硬件同步曝光**；设备时间戳也未做跨相机时钟同步。动态场景需要硬件触发。关闭占用相机的 pylon Viewer 等程序后运行。

依赖：`numpy`、`opencv-python`（含 GUI）、`pypylon` 和已安装的 Basler pylon 驱动。
